    关键分歧地图

      镜像问卷

      先各自独立填写，再挑分歧最大、最容易反复卡住的题目进入讨论。网页版把核心题和扩展题分开展示，并支持全文搜索。

      0 个条目

      情景讨论卡

      把抽象立场丢进现实情景，优先对齐你们真正卡住的争点，再判断是规则问题、边界问题、忠诚问题，还是安全感问题。

      0 张卡片

      深聊手册

      卡住时不要继续互相证明，改成追问“为什么这件事对我这么重要”。每组只挑最贴近当下冲突的 2-3 个问题即可。

      0 个追问

      结果记录页与风险雷达工作台

      下方记录面板和雷达评分会实时生成 YAML 内容，方便你直接复制到别处保存，同时继续保留网页内的填写与浏览体验。

      讨论记录表单

      工作台会根据原始 YAML 模板自动生成字段；你在这里填写、选择或评分后，右侧 YAML 会实时更新，方便直接复制保存。

      风险雷达实时视图

      维度映射来自原文，滑动评分会同步写回到 YAML。
